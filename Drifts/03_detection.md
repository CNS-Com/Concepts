# 🔍 Stratégies de détection des drifts

## Monitoring continu

- Analyse continue de l'infrastructure
- Comparaison état désiré vs réel
- Reporting et alertes automatiques

## Quelques outils

- Terraform : terraform plan
- Ansible : rôles ou collections de vérification, mode check (dry run)
- Cloud native : AWS Config, Azure Policy, etc.
- Outils dédiés : IP Fabric, Kentik, SuzieQ, Netpicker, etc.

## Bonnes pratiques

- Scans quotidiens automatisés
- Dashboard de conformité
- Intégration dans la CI/CD
